SPIRIT SCHEDULER
================


STEP 1  -  INSTALL
------------------
Drag "Spirit Scheduler" onto the Applications folder shown beside it.


STEP 2  -  ALLOW IT TO RUN  (once, and it is required)
------------------------------------------------------
This app is not registered with Apple, so macOS blocks it the first time.
It will simply not open, with no error and no message.

Open the Terminal app and paste this one line, then press Return:

    xattr -dr com.apple.quarantine "/Applications/Spirit Scheduler.app"

Nothing is printed if it works. You only ever do this once.

  (To find Terminal: press Command + Space, type Terminal, press Return.)

If you would rather not use Terminal: double-click the app, then open
System Settings > Privacy & Security, scroll to the bottom, and click
"Open Anyway" next to the message about Spirit Scheduler. Then open the
app again.


STEP 3  -  RUN IT
-----------------
Open Applications and double-click Spirit Scheduler.
Your browser opens automatically at the dashboard.

    Username:  manager
    Password:  spirit

Change the password after signing in.

The first launch takes about a minute: it prepares the database and
downloads the browser engine used to read the show calendar. Later
launches are immediate.


WHERE YOUR DATA LIVES
---------------------
    Home folder > Library > Application Support > Spirit Scheduler

That folder holds the database, your settings, and app.log. Installing a
newer version never touches any of it.

To enable syncing with Square, open settings.env in that folder with
TextEdit and paste your Square access token after
SQUARE_PRODUCTION_ACCESS_TOKEN= then restart the app.


IF SOMETHING GOES WRONG
-----------------------
Read app.log in the folder above - it records every startup and every
error. Send it on and the problem can be identified from it.

Nothing on this disk image contains passwords or access tokens.
