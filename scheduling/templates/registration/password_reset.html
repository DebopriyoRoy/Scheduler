Reset password

A password cannot be looked up — it is stored as a one-way hash, so nobody can read it back. Set a new one here instead.

  1. Press Write a reset code. The application saves a code into its own folder on this Mac, which only your macOS account can read — that is what stands in for the password you have forgotten.
  2. Open the file it names, copy the code from the first line.
  3. Paste it below with your new password. The code works once and lasts {{ code_minutes }} minutes.
